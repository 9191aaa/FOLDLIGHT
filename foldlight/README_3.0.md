# FOLDLIGHT / 折光 3.0

一款可以只用左手键盘或手柄游玩的纸海弹幕肉鸽。自动武器负责攻击；你负责走位、冲刺，并把可反射弹幕折进掌心再释放。

## 直接游玩

运行 `FOLDLIGHT.exe`。首次进入建议选择“开始序章”；序章会依次教授移动、冲刺、折域、主动道具和一次完整战斗。主模式“迷航”约 30–45 分钟，共三个区域、22 个大房间和三场多阶段 Boss 战。原十二航内容保留在“经典战役”。

## 操作

| 动作 | 键盘 | 手柄 |
|---|---|---|
| 移动 / 菜单选择 | WASD 或方向键 | 左摇杆 / 十字键 |
| 折域：按住收纳、松开返光 / 确认 | 空格（也支持 E） | A |
| 冲刺 | Shift | B |
| 主动道具 | Q | X |
| 暂停 / 返回 | Esc | Start |

青色与粉紫花瓣可以折返；带黑芯、金边和直线警告的弹幕不能反射，只能躲避或利用实体掩体。折域有内置冷却与六枚基础容量，原地连续按键不会取代走位。

## 存档与设置

- 迷航会在房间、奖励和路线选择阶段自动保存，可从标题继续。
- 旧版存档会自动迁移，经典战役进度保留。
- 设置提供音量、屏幕震动、手柄振动、高对比危险弹幕和全屏选项。
- 存档位于 Godot 的用户数据目录；删除游戏文件不会自动删除存档。

版本：3.0.0 · Windows x86-64 · Godot 4.6.3
