# 3.19.1 等量复射

按用户反馈，镜渊复影不再随玩家展开折域，也不再通过收纳拦截玩家自动武器。玩家松开一次有效收纳后，复影读取这次实际收纳数量，预告 0.8 秒，再发射同等数量的追踪弹。空收纳不触发；基础攻击仍是出生时复制的完整自动武器阵列。

数量来自玩家实际释放事件，范围 1–96，不受复影出生时的收纳容量限制。每次释放有递增序号，重复事件拒绝，连续释放逐件排队，每件都保留完整预告。每批最多 18 发；运行时只按真正生成的前缀数量回执，共享 260 发预算暂满时保留余量等待，不能把未生成的弹算成已经发出。复射弹本身不分岔，避免额外子弹破坏等量约定。有效伤害仍为 1 格，追踪有时限与转向上限。

暂停冻结预告与待发队列；硬直、阶段切换、死亡取消未完成复射，取消后旧事件不能重放。重开清空旧事件。玩家手动释放才触发，专注耗尽的失败反馈不制造新的攻击。首领栏显示本轮复射数量、预告时间与待发余量；教程演示同步调整。

自动武器复制出生时实际持有的所有武器及各自等级、有效射速、弹速、弹量和范围。六种实际行为继续共用运行时：折灯追踪、环针绕身发射、纸鸥折返、潮钟预警爆破、棱扇散射、日裁贯穿。玩家收纳时复影不再因为同步折域而停火；它仍遵守首领攻击窗口、射程、自己的动作预告和共享弹幕预算。出生后新增的武器或升阶不回写已存在的复影。

新增实际运行时验证同时装备六把武器并自然推进攻击窗口，不能只通过检查复制快照就声称六把武器实际开火。数量验证使用真实玩家释放信号、实际敌弹捕获与实际生成回执，包括总弹幕满额和部分空位。

2026-10-18 完整检查通过 132/132 项（含导入）。新增六武器集成场景有 51 条断言：真实装备与出生快照、自然攻击窗口中的六种实际弹体、暂停、预算占满后恢复，以及后生成复影与旧复影的构筑隔离。实际返弹测试验证后续收纳容量增加至 23 时仍按玩家的 23 发计数；占满 260 发预算时不挤出已有弹，释放 3 个空位后先发 3 发、保留其余 20 发，恢复空间后总数精确为 23。
