# 五幕纸海配乐

2026-10-17：替换原先约 26 秒的同一段双层循环，新增五套完整主题。全部为项目内编写的原创乐谱与离线加法合成音色，没有使用外部采样或在线音频服务。

| 场景主题 | 曲名 | 和声、旋律与配器 | 文件前缀 |
| --- | --- | --- | --- |
| 标题、航路、休息 | 纸灯归港 | D 大调色彩，毡琴长短句、轻拨弦、缓慢和弦呼吸 | `paper_harbor` |
| 纸礁 | 折浪纸礁 | A Dorian 色彩，错拍马林巴、明亮拨弦、轻手鼓问答 | `paper_sea` |
| 倒悬墨城 | 墨城回声 | E 小调色彩，玻璃音、高低声部答句、较长空间回声 | `paper_archive` |
| 无名日轮庭 | 无名日轮 | C 小调色彩，低音长线、柔和管乐、半拍鼓重心 | `paper_eclipse` |
| Boss | 日蚀心跳 | D 小调，低弦断奏、三加三加二重音、属和弦张力 | `paper_boss` |

每首有 16 小节，组织为 4 小节主题、4 小节变奏、4 小节 B 段，以及 2 小节减法段与 2 小节回归。旋律保留空拍；B 段改变旋律音区和配器，第 13–14 小节撤去大部分打击乐，避免一路平铺。五首分别编写和弦、旋律与伴奏，不是同一段音乐换调。

每首提供 `base` 和 `energy` 两个互补层。基础层包含完整旋律、和声与低音；能量层追加节奏和答句。两层同时从同一时间点播放，能量层按战斗强度淡入即可。不要将能量层作为独立背景循环，或把两层拼接播放。

所有文件固定为 **32,000 Hz / 双声道 / 80 BPM / 64 拍 / 48.000 秒 / 1,536,000 帧**。八个新文件加上两个替换文件合计 **2,526,156 字节（约 2.41 MiB）**。`paper_sea_*` 保留旧路径作为纸礁主题。Godot 导入设置均启用完整循环、零偏移、4 拍小节；新增资源的 UID 由 Godot 首次导入生成。

音乐在构建时生成并压缩；游戏内不合成、不计算混响。32 kHz 控制源音频与文件大小，但网页驱动会按 AudioContext 的实际采样率重采样，不能用源采样率估算最终网页占用。以常见 48 kHz 计算，每个 48 秒双声道 float32 AudioBuffer 约 17.58 MiB。网页版先淡出并释放旧主题，再加载下一主题；缓存适配器让播放节点共享已有缓冲，最多保留两层音乐缓冲，合计约 35.16 MiB 应用可见 PCM（不含解码临时数据与浏览器自身内存）。Windows / Android 原生版使用两组播放器进行 2.4 秒交叉淡化，完成后释放旧组。两个平台均不同时缓存全部十层。

## 波形与压缩质量

对最终 Ogg 文件重新解码后逐层校验，再校验 `base + energy` 全强度组合。峰值上限 0.35、相邻采样差上限 0.1、循环接缝差上限 0.006、首尾单样本绝对值上限 0.001。没有削波；打击乐使用带包络的低频/有限泛音，未添加持续白噪底。6 kHz 以上能量占比另设 0.0005 上限。

## 再生成与试听

在已安装 `numpy` 与 `imageio-ffmpeg` 的 Python 环境运行 `python tools/bake_music.py`。乐谱与波形生成不使用随机数；编码启用 FFmpeg bitexact，固定工具版本下 Ogg 可复现。工具版本变化可能改变 Vorbis 编码字节，但脚本会重新解码并验证全部音频条件。

生成器同时在 Git 忽略的 `build/test-runtime/web-audio-waveform/music-bake/` 输出完整混音、各主题 4 秒接缝试听、详细报告，以及 `FOLDLIGHT_五幕纸海_试听.mp3`。串听共 50 秒，按归港、纸礁、墨城、日轮、Boss 排列，每个主题 10 秒并在片段两端淡入淡出。中间 WAV 和 MP3 不随游戏导出。
