# 主动技能收藏 · 3.15

新获得的主动技能加入本局收藏，默认立即装备。之前的技能保留，可以重新选择；一次装备一件，仍使用 Q／手柄 X／手机原有技能按钮施放。

## 获取与切换

- 迷航在首次技能奖励和漂灯市选择技能，奖励过滤已经收藏的技能；收齐后提供其他成长。
- 无尽的第 3、7、11……次任务奖励中，第三个选项可提供尚未收藏的主动技能，其余选项和原有武器／成长节奏保留；收齐后恢复原奖励。
- 单人可在暂停菜单打开技能收藏。领奖时也能打开收藏再返回三选一，不消耗本次奖励。
- 好友赛保持不能手动暂停的规则，仅在领奖期间切换技能。收藏页沿用领奖暂停状态，不增加生存计分。
- 各技能独立冷却，切换不会刷新。战斗中收藏的技能一起恢复冷却；暂停和领奖时停止恢复。
- 收藏仅属于当前一局；重新开始会重置。迷航继续存档保留收藏、当前装备与冷却；旧 v1/v2 存档中的单件技能迁移到收藏。

## 界面与用词

统一使用“主动技能”，奖励说明区分“获得并装备”“已收藏”“当前装备”。技能效果先说明用途，再交代冷却和必要限制；自动武器、主动技能与数值强化使用不同的类别标记和确认文案。

手机保留一个战斗技能按钮，收藏管理放在菜单中，不增加战斗按钮或混用键鼠提示。奖励阅读保护、返回确认、刘海安全区、旋转遮挡以及减弱动态设置继续适用。
