# Windows、Android 与网页好友竞赛

标题页的「好友联机」使用同一套游戏内房间界面和 HTTP 房间协议。迷航与无尽单人不需要网络。好友模式是同一种子、相同基础机体的独立生存竞赛；双方不会出现在同一战场中。

## 玩家操作

1. 打开「好友联机」，填写称呼。大陆临时入口需要将发布时提供的**完整试玩链接**粘贴到「联机入口」，包括链接中的鉴权参数。
2. 一人创建房间，把 7 位房间码发给另一人。双方须连接同一房间后台；入口可以不同，但必须转发到同一个后台。
3. 双方点「准备出发」。真实战斗场景加载后才通知服务器准备完成；服务器统一倒数 5 秒。
4. 比较有效战斗时间，选择奖励不计时。离开须确认；开局后离开按弃赛处理。断线满 30 秒停止本地计分并由后台处理结果。

免费临时入口会过期，过期后需要粘贴新链接。默认备用入口为原 Sites 站点，其大陆网络可达性不作保证。游戏不会自动购买任何域名或服务。

本版独立房间后台为 `https://foldlight-room-service.foldlight-papersea-2026.workers.dev`。Sites 和新版腾讯海外试玩入口均转发到该后台；大陆用户优先粘贴完整腾讯试玩链接，直接访问 Workers 域名仍受所在网络影响。旧腾讯全球项目的函数节点出站超时，不能作为本版联机入口。

## 实现边界

- `FoldlightWebRaceBridge` 保留原 Sites 外层网页协议；游戏内大厅通过同一桥接器驱动真正的无尽场景。
- `native_race_client.gd` 支持 Windows、Android 和独立静态网页的 HTTPRequest。协议为 `endless_race_v3`；不同规则版本在准备与心跳时被后台拒绝。
- 当前比赛身份、玩家令牌和预览 Cookie 只存在内存中。只保存玩家主动选择的服务入口及称呼；不会持久化房间身份以重复加入已开局的比赛。
- EdgeOne 预览签名对应入口路径。原生先请求完整入口，读取 `eo_token` / `eo_time` Cookie，然后只向同一服务域名发送 Cookie；不跟随重定向转发玩家令牌。网页使用浏览器自己的同源 Cookie。
- 心跳每秒最多发一次，同一客户端只允许一个在途请求。请求超时为 12 秒。断线等待不重置种子、战斗时间或个人进度；离开房间会清除当前身份并回到统一标题页。
- 手机房间表单使用可滚动布局、焦点跟随、软键盘留空和独立触控尺寸；比赛条带为手机 HUD 保留顶部空间。
- 后台约束时间增长、单次实例和版本，但该模式仍是好友竞赛，不提供强对抗反作弊保证。

## 验证

默认离线回归包含 `test_native_race_lobby.gd`，覆盖预览鉴权范围、入口切换清理、表单尺寸、退出确认和超时禁止重开。

真实 HTTP 验证需先运行 v3 房间 API，并通过环境变量 `FOLDLIGHT_RACE_TEST_ENDPOINT` 注入服务入口，再执行 `res://tools/verify_native_race_http.gd`。脚本创建两个独立原生 HTTP 客户端并驱动一个真正的无尽场景，验证建房、加入、准备、倒数、同种子、实战计时、死亡结果以及离房回标题。测试日志不打印入口、玩家令牌或 Cookie。

`res://tools/capture_native_mobile.gd` 用真实渲染器截取共享场景。提供上述环境变量时还会创建真实服务房间并截取比赛界面。它在桌面显式选择手机布局；不能替代 Android 安装与真机触摸测试。
