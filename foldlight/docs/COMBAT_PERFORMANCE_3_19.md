# 镜像首领与持续围攻性能 · 3.19

2026-10-18，本机 Windows、Godot 4.6.3 原生调试引擎、OpenGL 3.3 Compatibility、NVIDIA GeForce RTX 5070 Ti Laptop GPU（驱动 580.88）。测量窗口 1280×720、逻辑画布 1920×1080；独立用户数据目录，窗口有焦点，FPS 不限，未开启低处理器模式。测量期间没有其他 Godot、浏览器 GPU 检查或 Android 模拟器同时运行。

三组最终持续压力样本的帧间隔中位数为 **49.863 / 58.746 / 59.529 ms**。其倒数约为 **20.1 / 17.0 / 16.8 FPS**，不是整局平均帧率。这些结果仍明显偏慢，**不能称为高密度性能达标、稳定 60 FPS 或实体手机流畅**。没有通过减少怪物、关闭首领招式或隐藏绘制获得结果。完整原始数据、两轮比较和视觉检查摘要见 [COMBAT_PERFORMANCE_3_19.json](COMBAT_PERFORMANCE_3_19.json)。

## 条件与复测边界

使用生产地图、真实共享 AI、地形、碰撞、自动选敌和完整绘制。玩家静止无敌、持有六把 Lv.5 自动武器且不收纳；目标使用夹具生命维持人数，首领维持第三阶段。初始化后冻结自动刷怪和任务进度，建立真实护送任务，继续推进毒雾、围猎、反向区和轰炸时钟。

首领阵容为礁冠炮城、潮汐织母、镜渊复影、断页行刑者、折纸裁判、蚀日双铃。毒怪通过真实、带来源的排毒信号建立 24 片持续 60 秒的毒雾，随后自然排毒、合并和过期仍照常执行。两组补弹测试至少运行 20 秒，自然样本至少 35 秒；每组总显示帧至少 360，前 31 帧排除后才计算表内样本。六首领补弹组因帧数条件延长至 21.337 秒。

相较 3.18 的首领压力样本，本轮加入实际镜像武器、24 片持续毒雾和首领战轰炸，内容更重，不能当作相同内容的跨版本 A/B 测试。以上也是持续高生命目标围攻，不代表正常游玩的整局平均值、长时间存档稳定性或安卓设备表现。

本轮先完整测量，再合并镜像候选扫描、简化战斗状态快照，并仅在斩杀增益需要时读取目标最大生命。随后同夹具完整复测一次；未根据结果反复追测挑选较快的一次。

| --- | ---: | ---: |
| 80 普通敌人 + 补弹 | 47.773 / 61.562 ms | 49.863 / 63.130 ms |

两个首领样本 P95 下降，但中位数没有一致改善。每项只有一次前后样本，存在时序、温度和系统负载波动，**不能据此宣称统计显著、整体性能提升，或将差值完全归因于这几处修改**。这轮应按真实局限交付功能，后续仍需针对持续高密度负载优化。
