# 手机网页操作

手机使用同一公开网站，以横屏游玩。左侧摇杆移动，右侧按住折翼收纳、松手返光，另有冲刺和主动技能；武器继续自动攻击。迷航与无尽共用这一套操作。

## 与电脑隔离

- 触控输入保存在独立状态中，不修改键鼠和手柄的 InputMap，不向全局 Input 写入合成按下／释放。
- 网页入口提供「自动识别／手机触控／电脑键鼠」，并记住手动偏好。自动识别综合设备提示和主要指针能力，手机、平板可手动纠正识别结果；桌面缩小窗口不会自动出现虚拟摇杆。
- 进入游戏时确认并固定本局布局，网页外壳与游戏通过同一个 `layout` 值使用手机或电脑界面。触屏笔记本点击屏幕、手机连接键盘／鼠标、旋转或改变窗口尺寸均不会在本局切换 UI。返回航站后可重新选择。
- 同时按摇杆、折翼和冲刺时，各手指分别归属一个操作；在控件外抬手、系统取消触点、失焦及切换界面均需释放正确的所属状态。
- 暂停、奖励、航图、介绍和结算不接收战斗操作。奖励保留阅读时间，并等待旧触点全部释放；触点取消不触发返光或确认。

## 界面与网页外壳

手机游戏舞台铺满浏览器可用空间，不依赖浏览器原生全屏。竖屏提示横放，返回航站和好友房间退出使用确认框。战斗 HUD 使用紧凑布局，为底部双手操作留出位置；所有模式保留相同的状态含义。

浏览器桥 `window.FoldlightTouch` 传递已确认的布局、安全边距、触控取消序号和输入暂停状态。游戏将合法 `layout: mobile | desktop` 视为权威，不因一次触摸或按键自行换界面；旧桥与原生端仍保留能力判断。旋转屏幕或打开网页确认框只取消触控，不暂停好友比赛的计时，也不改变竞赛成绩规则。

## 验证边界

回归需覆盖多指移动与收纳、冲刺、触点取消、模态切换、横竖屏、安全边距、桌面输入与好友竞赛。浏览器设备模拟能验证布局和触摸事件；它不能代替所有 Android／iOS 真机的浏览器兼容性、性能和握持手感验证。

2026-10-15 验证完成：

- 新增独立多指、弹窗触点、Boss 继续、手机布局和指针换场回归，并复跑受影响的既有检查。实际两个弹窗的事件分发覆盖旧触点被另一弹窗消费的情况。
- 真实 Web 引擎在 844×390、667×375、640×360 手机模拟画面通过三指移动／折翼／冲刺、暂停／设置、旋转清理及返回确认，所有日志无引擎错误。手机虚拟按钮直径至少 40 CSS 像素。
- 桌面网页通过输入、返回／重启、异常恢复回归，缩小电脑窗口不会启用手机布局。
- 两个桌面浏览器，以及手机与桌面混合浏览器的好友赛，均通过同种子开局、真实计时、退出结算；手机旋转和退出确认取消不暂停比赛，也不替换引擎。
- 网页音频、生命周期及触控桥共 18 项测试与 TypeScript 检查通过；Web／Windows 导出无错误，Windows 启动通过。

触屏换场还修复了两处真实输入错误：标题进入无尽、无尽结果返回标题会先锁定重复请求，再在当前输入分发结束后换场，避免触点释放访问已经离开的按钮。

同日追加设备界面隔离验证：6 次真实网页引擎加载覆盖触屏电脑自动使用电脑版、手机自动识别、手动互换、局内外设／窗口变化保持布局、刷新恢复偏好及重置自动。网页外壳、触控桥与游戏三层结果一致，日志无引擎错误。另通过手机多指、桌面返回／异常恢复和手机＋电脑好友赛回归；设备识别、存储、桥接、音频与生命周期共 33 项网页测试通过。
