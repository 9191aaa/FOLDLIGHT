# FOLDLIGHT 3.11.0 · 2026-10-17

本版同时交付内嵌资源的 Windows 单文件 EXE、已签名 Android APK 与网页资源。

## 游戏与操作

- 新敌人「烬火纸雷」在中后段出现，接近玩家后停住，预警 1.5 秒再自爆；提前击杀可拆除，爆炸遵守护盾、冲刺及受击无敌规则。
- Windows、Android 和网页共用好友大厅及 `endless_race_v3` 规则。同一种子各自生存，比有效战斗时间，不是两人在同一张战场合作。
- 手机独立触控、安全区和任务栏布局；房间输入在软键盘上方滚动显示，系统返回先收键盘、再处理暂停或离开确认。
- 离开确认阻断键盘、手柄与触摸的手动战斗输入，自动攻击、伤害和竞赛计时继续。取消确认立即恢复操作。
- 服务器结算立即停止战斗；停留结算页超过 30 秒不会误报断线。
- 弹幕缓存形状、限制短时闪光数量，保留碰撞、速度及随机序列。网页继续使用已验证的音频循环修复。

## 构建与验证

- 默认 67 项 Godot 检查通过；最后的输入隔离改动另通过玩家战斗、共享输入、手机触控回归。
- 两个真实 HTTP 客户端驱动实际无尽场景的 32 项检查通过，覆盖倒数、同种子、比赛计时、输入隔离、终态与安全退出。
- Windows 交付 EXE 使用真实 OpenGL 渲染启动并正常退出；正式 APK 已验签、安装并进入实际无尽战斗。
- API 35 Android 模拟器验证软键盘输入、房间码滚动、返回键和前后台恢复；移动网页实际引擎验证输入框触摸聚焦及文本输入。
- 独立房间后台通过 8 项单元/并发回归和 54 项本地 D1 API 检查；Sites 转发通过 11 项边界检查。
- 同一桌面 GPU 压力场景平均帧时约 11.2 ms，P95 约 16.3 ms。该数值不代表手机性能；不保证浏览器在系统内存不足时永不回收。

真实手机的发热、厂商系统及各大陆运营商仍需实际设备验证。在线入口的发布与可达性以交付说明中的有效链接和验证范围为准。

## 后台维护

独立服务源码位于仓库的 `services/room-service/`，使用免费 Cloudflare Workers 与 D1。Sites 通过 `FOLDLIGHT_ROOM_SERVICE_URL` 指向同一服务；腾讯独立入口转发固定房间路由。

腾讯全球项目的大陆函数节点无法连接当前 Workers 域名，因此另建海外免费试玩项目，保留原全球项目用于回退。临时试玩链接仍需鉴权，约 3 小时有效。原生客户端须粘贴发布时提供的完整链接；不在安装包中固化易过期的签名。

签名密钥保存在本机忽略的 `build/signing/`；以后 APK 更新须保留同一密钥，不得把密钥或本地登录凭据上传到源码或网站。
