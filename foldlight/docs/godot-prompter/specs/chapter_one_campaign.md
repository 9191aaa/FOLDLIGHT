# FOLDLIGHT 第一章扩展规格

## 产品定位

本版本把单局街机流程改造成可上架叙事游戏的第一章《残灯渡海》。核心操作仍只有移动与「按住收纳、松开返还」，但章节具有固定编排、剧情节点、首次遭遇教学、局外资源与永久成长。一次通关包含六个战斗潮段和一个最终幕，目标时长约 10–14 分钟。

## 章节流程

```text
标题 / 继续第一章
  → 首次守灯课（确认式暂停）
  → 潮一 静水 → 技艺封印 1
  → 潮二 纸鸢 → 技艺封印 2
  → 潮三 回声 → 技艺封印 3
  → 潮四 风眼 → 技艺封印 4
  → 潮五 赤轮 → 技艺封印 5
  → 潮六 倒流 → 技艺封印 6
  → 终潮 墨月 → 第一章尾声 / 结算
  → 折光庭（使用余辉购买永久成长）
```

每个战斗潮段持续 72 秒，在 20 秒和 46 秒触发固定仪式事件，段末生成潮使。前三段建立收纳与返还节奏；第四段叠加状态管理；第五段引入锁线冲撞；第六段混合冲撞、逆折域与四秒回迹。

## 运行状态与暂停教学

`RunMode.BRIEFING` 是游戏内模态状态，不暂停 SceneTree。进入时：

- `FoldlightGame._physics_process()` 立即停止战斗模拟，敌人、弹幕、计时、玩家位移均不推进。
- `Player.suspend_for_overlay()` 清除当前移动和折叠输入，但保留已经收纳的花瓣，避免松键丢失资源。
- `_process()` 只让背景以 36% 速度呼吸，并持续绘制 HUD。
- 玩家按折叠键 / 手柄 A / 确认键后才进入下一页；最后一页退出时给予 0.7 秒安全无敌。

暂停页有四类：`stage`、`story`、`enemy`、`effect`。章节标题每潮显示；基础操作、剧情、敌人与异常状态只在首次确认时写入独立的 `acknowledged_intros` / `story_flags`，不会因为图鉴解锁而误判为玩家已经读过。

## 新敌人状态机

### 冲角 RAM

```text
STALK → TELEGRAPH → CHARGE → RECOVER → STALK
```

- STALK：在中距离环绕，等待主攻击。
- TELEGRAPH：0.82–0.95 秒金色冲线；前 0.30 秒可微调，之后锁定方向。
- CHARGE：840–920 px/s 沿锁定直线冲撞，不再追踪；只有此状态接触会伤害玩家。
- RECOVER：撞墙或冲刺结束后停顿；此时返光额外造成 1 点伤害。撞墙释放一圈可收纳花瓣，形成「闪开 → 收纳震波 → 回身反击」闭环。

### 回痕兽 REWINDER

```text
ROAM → TELEGRAPH → REWIND → RECOVER → ROAM
```

- ROAM：用 54 点固定环形缓冲区，每 0.08 秒记录位置，不在逐帧堆内存。
- TELEGRAPH：冻结最近四秒路径并以橙色折线和反向箭头展示 1.02–1.20 秒。
- REWIND：以 900–980 px/s 沿快照反向冲回；只有此状态接触会伤害玩家。
- RECOVER：冲完停顿并承受额外返光伤害，然后重建路径历史。
- 高速接触采用线段扫掠检测，避免跨帧穿过玩家。

## 折光庭与存档

结算根据击杀、收纳、胜利与评级奖励 1–24 点「余辉」。标题或结算界面按 `C / 手柄 X` 进入折光庭，可购买四条永久成长：灯骨、潮忆、深匣、返锋。成长只改变开局基础值，不引入新的操作键。

存档版本为 3，新增字段：

- `glimmer`、`last_glimmer_reward`
- `meta_upgrades`
- `story_flags`、`acknowledged_intros`
- `highest_tide`、`chapter_one_complete`

迁移必须为旧档补齐字段、钳制升级等级，并保留成绩、设置、成就和图鉴数据。测试模式使用 `-- --test-mode` 禁用用户档读取与写入。

## 动态场景

七幕分别使用镜海、横风纸鸢、回声花庭、无灯风眼、赤轮苇原、倒流回廊和墨月裂相母题。背景持续运动，但不只是装饰：敌弹密度驱动能量值，收纳、返还、击杀、冲撞和 Boss 裂相驱动脉冲；教学暂停时场景仍缓慢呼吸，明确表达「世界被按住，但画面没有死」。

## 验收条件

- 无首次教学自动消失；所有必要介绍等待玩家确认，且确认前战斗世界不推进。
- 六潮各有独立场景名、目标、事件与敌人配比，第七幕为完整 Boss 和胜利结算。
- 冲角与回痕兽均有可读预警、明确危险帧、反击窗口和首次遭遇页。
- 局外成长能够购买、持久化、迁移并在新一局实际生效。
- 键盘可用左手完成 `WASD + Space/E + C/Esc`；手柄可用左摇杆、A、X、Start 完成全部流程。
- 1920×1080 基准画布在 4:3 和宽屏保持完整；最大敌人、弹幕和粒子压力下满足桌面 60 FPS 预算。
