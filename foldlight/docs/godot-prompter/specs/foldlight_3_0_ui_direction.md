# FOLDLIGHT 3.0 界面与视觉方向

## 视觉命题

**深海纸艺航图**：以靛黑无边海面承载带纸纤维感的轮廓与刻线，青绿折光只表示玩家、可反射物与正向操作，暖金只表示不可反射危险、诅咒和终局压力；界面像一张被光切开的航海海报，而不是一叠通用卡片。

## 内容层级

1. **标题主视觉**：`FOLDLIGHT / 折光`、动态折痕与一个唯一主按钮“开始迷航”；继续进度存在时主按钮改为“继续迷航”。
2. **支持入口**：十分钟序章、经典十二航、设置与退出保持次级权重，不与主按钮争夺视线。
3. **局内信息**：战斗 HUD 只常驻生命、折域容量/冷却、冲刺、武器、主动道具、区域与房间进度；路线图和构筑详情按键呼出。
4. **决策界面**：路线节点使用真正的航线拓扑；三选一奖励允许使用三张“大幅纸签”，因为此处比较并列选项就是核心任务。
5. **结算行动**：先总结本局路线、Boss 与构筑，再给“再次迷航 / 返回标题”两个清晰动作。

## 交互命题

1. 标题出现时由一条青绿折缝划开暗海，标题与按钮沿折痕依次漂入；动画短、可跳过，不阻断输入。
2. 路线图以已走航线逐段描亮，当前节点轻微呼吸，下一房间只突出可达分支；方向键移动焦点，确认键选择。
3. 战斗反馈优先使用局部轮廓、冷却弧和短促位移；同一帧的反射/命中合并呈现，避免全屏闪白、连续停顿和震屏破坏手感。

## 布局与输入规则

- 基准画布 1920×1080，保留经典战役的 `viewport + keep` 固定构图；新界面内部全部使用锚点和容器，在 1280×720 与窗口缩放下仍完整可读，超宽屏以安全留白呈现。
- 所有可交互控件最小高度 52 px，必须有键盘/手柄焦点态、显式邻接与进入界面后的默认焦点。
- 单手键盘继续使用方向键或 WASD 移动，空格折域，Shift 冲刺，E 主动技能；菜单允许方向键/WASD + 空格/Enter 确认，Esc 返回。
- 中文为首发语言；新增用户可见文本统一通过语义翻译键获取，动态数字在翻译后格式化。
- 奖励、Boss 警告与新机制首次介绍可暂停决策，但不使用长段说明；每条说明必须包含“它是什么”和“此刻怎么应对”。

## 视觉验收

- 截去文字后仍能仅凭颜色、轮廓和运动区分：玩家攻击、可反射敌弹、不可反射敌弹、地形危险、可交互门。
- 标题、路线、战斗与结算共享同一字体层级、色彩语义和折线母题，但构图各不相同。
- 任何战斗事件都不得叠加超过一次强震屏或一次明显命中停顿；高频伤害使用聚合数字和局部粒子。
