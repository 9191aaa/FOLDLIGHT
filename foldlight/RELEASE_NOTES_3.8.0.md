# FOLDLIGHT / 折光 3.8.0

3.8 是第一轮自主产品迭代，保留 3.7 的全部内容，集中强化返光清杂的连续爽感。

## 返光接力

- 返光导弹击杀普通敌人后，会沿现有绕墙路径转锁另一名未命中的敌人。
- 每枚返光最多接力一次；Boss、非致死命中、回声弹和无可达目标不会触发。
- 接力复用原弹体，不增加场上投射物数量，也不会突破 260 弹幕上限。
- 接力不消耗已有“透页光”穿透次数，保持局内构筑兼容。
- 接力时出现 0.24 秒金色脉冲与加粗尾迹，并按剩余路径补足飞行寿命。
- AStar 只接受完整可达路径，不再把部分路径误判成可达后直线穿墙。

## 验证

- 新增返光接力专用测试，覆盖单次上限、同实例复用、穿透兼容、回声防递归、Boss 排除和不可达目标。
- 2.0 敌人与弹幕精确契约、返光绕墙、完整 22 房流程和 260 弹性能测试全部通过。
