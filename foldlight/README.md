《折光》是一款支持单手键盘与手柄的纸海弹幕肉鸽。武器自动开火；玩家只需移动、冲刺、展开折域收纳可反射弹幕，并在松开时将光返还给敌人。黑芯金边弹幕不能反射，必须靠走位、冲刺或实体掩体应对。

主模式是一局约 30–45 分钟的三域分支迷航：36 个固定设计的大房间、战术地形、威胁预算遭遇、六把自动武器、六件主动技能、36 项局内升级，以及六名具备不同弹幕机制的 Boss（每个区域选一名）。肉鸽战斗以 2.0 为基底，漂游灯、扇潮灯、织潮灯、冲角、绽灯、汲光灯、逆折者与回痕者的原造型和原攻击规则全部回归；返光击杀普通敌人后会沿可达路径接力一次。新机制怪首次登场会暂停战斗并动态演示规则与解法。正式美术沿用纸海折光风格并细化，普通房间每区拥有十二种固定构图。无尽生存使用三张 7680×5120 至 8256×5504 的大地图、双成长轴与七类任务；奇数次任务提供武器补给，偶数次提供“火力 / 折域机动 / 续航”三路成长。历史存档仍可读取，设置和迷航进度不受故事模式移除影响。

## 启动

Windows 发行包运行 `FOLDLIGHT.exe`；Android 安装带发布签名的 APK。项目环境也可运行 `run_foldlight.ps1`。手机使用专门的触控界面，房间与操作说明见 [跨平台竞赛](docs/NATIVE_RACE.md)。

首次选择“开始迷航 · 操作教学”，会在真实房间中教授移动冲刺、折域返光和自动武器／主动技能。

## 操作

| 动作 | 键盘 | 手柄 |
|---|---|---|
| 移动 / 菜单选择 | WASD 或方向键 | 左摇杆 / 十字键 |
| 折域：按住收纳、松开返光 / 确认 | 空格（也支持 E） | A |
| 冲刺 | Shift | B |
| 主动技能 | Q | X |
| 暂停 / 返回 | Esc | Start |

折域具有 1.5 秒内置冷却和八枚基础容量；收纳弹幕会按 2.0 的宽扇面错峰返航并自动追敌。冲刺基础冷却为 2 秒。设置中可调整音量、屏幕震动、手柄振动、无边框全屏，并启用高对比危险弹幕；游戏不会请求会切换显示器分辨率的独占全屏。

## 内容与存档

- 三个区域会使用不同的墙体、折射柱、墨池与水流布局。
- 原八种敌人构成每个区域的战斗主体；固定炮塔、系铃增益单位与墨守控场单位只按职责配额叠加。
- 锻造房提供自动武器获取与升阶，漂灯市提供新的主动技能，已选技能保留在本局收藏中；普通奖励优先拓宽局内构筑。
- 迷航会在房间、奖励和路线选择阶段自动保存，可从标题继续。
- 配乐分为归港、纸礁、墨城、日轮与首领五个主题，每首 48 秒、16 小节，包含主副旋律与段落变化。战斗压力逐渐叠加节奏层；暂停、三选一和击破演出会收束音乐，切回场景继续原有乐句。手机网页切曲先淡出并释放旧音频，避免长期游玩累积缓存。
- 局外成长以横向解锁为主；数值构筑集中在当局。
