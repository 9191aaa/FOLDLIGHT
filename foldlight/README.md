# FOLDLIGHT / 折光 3.9.0

把危险折进掌心，再让整片光返航。

《折光》是一款支持单手键盘与手柄的纸海弹幕肉鸽。武器自动开火；玩家只需移动、冲刺、展开折域收纳可反射弹幕，并在松开时将光返还给敌人。黑芯金边弹幕不能反射，必须靠走位、冲刺或实体掩体应对。

3.9 主模式是一局约 30–45 分钟的三域分支迷航：36 个固定设计的大房间、战术地形、威胁预算遭遇、六把自动武器、六件主动道具、36 项局内升级，以及三名具备多阶段弹幕和场地限制的 Boss。肉鸽战斗以 2.0 为基底，漂游灯、扇潮灯、织潮灯、冲角、绽灯、汲光灯、逆折者与回痕者的原造型和原攻击规则全部回归；返光击杀普通敌人后会沿可达路径接力一次。新机制怪首次登场会暂停战斗并动态演示规则与解法。正式美术沿用纸海折光风格并细化，普通房间每区拥有十二种固定构图。另有完整的“无尽生存”模式：6144×4096 固定战场、双成长轴、三类任务，以及每次固定提供“火力 / 折域机动 / 续航”三路选择的局内进化。原三章十二航完整保留为“经典战役”，旧存档会自动迁移。

## 启动

发行包中运行 `FOLDLIGHT.exe`。项目环境也可运行 `run_foldlight.ps1`。

首次进入建议选择“开始序章”；五个短步骤会在真实战斗房间中教授移动、冲刺、折域、主动道具与完整遭遇。

## 操作

| 动作 | 键盘 | 手柄 |
|---|---|---|
| 移动 / 菜单选择 | WASD 或方向键 | 左摇杆 / 十字键 |
| 折域：按住收纳、松开返光 / 确认 | 空格（也支持 E） | A |
| 冲刺 | Shift | B |
| 主动道具 | Q | X |
| 暂停 / 返回 | Esc | Start |

折域具有 1.5 秒内置冷却和八枚基础容量；收纳弹幕会按 2.0 的宽扇面错峰返航并自动追敌。冲刺基础冷却为 2 秒。设置中可调整音量、屏幕震动、手柄振动、无边框全屏，并启用高对比危险弹幕；游戏不会请求会切换显示器分辨率的独占全屏。

## 内容与存档

- 三个区域会使用不同的墙体、折射柱、墨池与水流布局。
- 原八种敌人构成每个区域的战斗主体；固定炮塔、系铃增益单位与墨守控场单位只按职责配额叠加。
- 锻造房提供自动武器替换，漂灯市提供主动道具替换；普通奖励优先拓宽局内构筑。
- 迷航会在房间、奖励和路线选择阶段自动保存，可从标题继续。
- 局外成长以横向解锁为主；数值构筑集中在当局。

## 验收

项目包含经典全流程、3.0 全路线、输入、存档迁移、遭遇职责、36 升级、地形、Boss、长时模拟与渲染压力测试。发行前运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\run_godot_local.ps1 --headless --path . --script res://tests/integration/test_full_rogue_route_3_0.gd
```

开发测试统一通过 `tools/run_godot_local.ps1` 启动。它只把 Godot 的测试日志、缓存和 `user://` 重定向到项目内的 `.codex-runtime`，不会读取或改写玩家真实存档，也不需要 Codex 为 Windows 用户目录反复申请写入权限；正式导出的游戏仍使用系统标准用户存档目录。
