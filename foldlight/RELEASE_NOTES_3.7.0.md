# FOLDLIGHT / 折光 3.7.0

本版重新以 2.0 战斗手感为基底，完成肉鸽主模式的内容、美术反馈与稳定性收口。

## 核心变化

- 36 个固定设计的大房间，每区 12 种构图；地形、掩体与刷怪位置均参与战斗。
- 2.0 的八种基础敌人、弹幕造型和受击反馈回归；新机制敌人首次出现时会动态演示攻击与解法。
- 折域基础容量 8 枚，1.5 秒内置冷却；返光会绕开墙体追踪可达敌人。
- 冲刺冷却 2 秒；HUD 独立显示生命、折域、冲刺、主动道具和自动武器。
- 第二房间连续提供“局内强化 + 主动道具”两次三选一，选择期间不会受到伤害。
- 三名 Boss 更新生命、弹幕、场地限制和特效；第一章冲击波保留明确安全缺口。
- 新增完整无尽生存模式：6144×4096 固定战场、敌人与玩家双成长、三类任务、三选一进化、死亡结算与重开。
- 旧全屏设置首次启动会安全迁移为窗口化；显示模式切换延迟到窗口稳定后执行，并且从不请求独占全屏。

## 操作

- 移动：WASD / 方向键 / 左摇杆
- 折域：空格或 E / 手柄 A
- 冲刺：Shift / 手柄 B
- 主动道具：Q / 手柄 X
- 暂停：Esc / Start
- 暂停菜单中依次输入“上上下下左右左右”可切换流程浏览用无敌模式。

Windows x86-64 · Godot 4.6.3
