# FOLDLIGHT / 折光 3.9.0

3.9 是第二轮自主产品迭代，保留 3.8 的返光接力与 3.7 的全部正式内容，集中解决无尽模式成长选择不清楚、部分奖励永远抽不到和描述有效果却没有真正进入战斗的问题。

## 三路任务进化

- 每次任务完成都固定提供“火力 / 折域机动 / 续航”三路各一张，不再出现某一路缺席或三个奖励语义混乱。
- 两轮奖励交替为：潮返 / 横风、开阔折域 / 动纸、定灯 / 清流；两轮即可看到全部六项奖励。
- 卡片直接显示路线、奖励名、下一等级和完整效果，键盘与手柄焦点规则保持不变。
- 任务奖励只影响本局，不推进敌潮成长、吸收成长，也不写入局外 Profile。

## 奖励实效修复

- 横风的“穿透 +1”现在会让同一发自动武器真正贯穿直线上的后排敌人；击杀前排后按 UID 重查目标，不会发生数组下标漂移。
- 清流改为展开折域时移动速度 +10%、受击保护 +0.08 秒，两项均由实际运行时读取。
- 吸收进化“长息”移除不存在的专注资源加成，改为折域移动速度与受击保护。
- 吸收进化“连光 / 完美轨道”的返航连锁现在真实生效：同一枚返航光会沿可达路线改锁未命中的下一目标，不额外生成弹体。
- 自动射击、返航、移动、冲刺、收纳和受击保护统一从同一套有效战斗数值计算，减少卡片与实战不一致。

## 验证

- 新增 3.9 奖励路线集成测试，覆盖固定三路、奇偶轮换、全部六项效果、直线双目标穿透、返航连锁、选择期间伤害冻结、卡片文案、局内隔离与重开清零。
- 2.0 战斗契约、返光接力、无尽流程、Boss、奖励安全、完整 22 房路线和 260 弹性能回归均通过。
